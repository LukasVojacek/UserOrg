Princip nasazení

DB odpovídá schématu main (__EFMigrationsHistory končí na 20260416054631_AddUserNameIndexToUserTable). Pending jsou 3 EF migrace, ale ne všechny se nasazují stejně:

0.4 Pre-flight kontrola dat

-- musí vrátit přesně 3 vadné resources a 0 duplicitních názvů
SELECT pr.Name, COUNT(DISTINCT l.ProviderId) AS Providers
FROM ProjectResource pr
JOIN AssignedLocation al ON al.ProjectResourceId = pr.Id
JOIN Location l ON l.Id = al.LocationId
WHERE pr.IsDeleted = 0
GROUP BY pr.Name HAVING COUNT(DISTINCT l.ProviderId) > 1;
-- očekávané: OPEN-33-82, VLQ-FI, VLQ-PL-P0001
Objeví-li se 4. řádek — zastav a přehodnoť split skript.

1 M1 — ProviderId + FK ruční

sqlcmd -S <server> -d UserOrgDBContext -U <user> -P <pwd> -C -b \
  -i docs/ddd-migration/sql/0026-m1-add-projectresource-providerid.sql
-- verifikace
SELECT COL_LENGTH('dbo.ProjectResource','ProviderId') AS HasColumn;          -- <> NULL
SELECT MigrationId FROM __EFMigrationsHistory WHERE MigrationId LIKE '%AddProjectResourceProviderId';
✓ Sloupec + FK existují, history řádek …143515 přidán. Všechny ProviderId zatím NULL — správně. M2 ještě NEspouštěj.

2 Data fix — split + backfill ruční

sqlcmd -S <server> -d UserOrgDBContext -U <user> -P <pwd> -C -b \
  -i docs/ddd-migration/sql/0026-projectresource-per-provider-split.sql

Jedna transakce s verify-before-commit: backfill ProviderId u 74 čistých resources, split 3 vadných (3 → 6), repoint alokací, duplikace project-assignments.

✓ Výstup: StillSpanningMultiProvider = 0, Invariant5Violations = 0, ProviderNameDupes = 0, transakce COMMITne. Jinak self-ROLLBACK (chyba 50026).

5 Finální verifikace

-- A) žádný resource přes >1 providera
SELECT COUNT(*) AS StillShared FROM (
  SELECT pr.Id FROM ProjectResource pr
  JOIN AssignedLocation al ON al.ProjectResourceId=pr.Id
  JOIN Location l ON l.Id=al.LocationId
  WHERE pr.IsDeleted=0 GROUP BY pr.Id HAVING COUNT(DISTINCT l.ProviderId)>1) t;   -- 0

-- B) invariant #5
SELECT COUNT(*) AS Inv5 FROM AssignedLocation al
JOIN Location l ON l.Id=al.LocationId
JOIN ProjectResource pr ON pr.Id=al.ProjectResourceId
WHERE pr.IsDeleted=0 AND pr.ProviderId IS NOT NULL AND pr.ProviderId<>l.ProviderId;  -- 0
  • A = 0, B = 0; smoke test v2 resource + request endpointů přes Gateway
  • Resources s 0 alokacemi → ProviderId = NULL (ADR-0026 edge); v1 řádky → Slug = NULL (ADR-0024)
