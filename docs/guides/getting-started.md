# Getting Started Guide

Local setup, running the application, and basic operations.

## Prerequisites

### Required

- **.NET 8 SDK** or later
  - Download: https://dotnet.microsoft.com/download
  - Verify: `dotnet --version`

- **Git** for cloning the repository
  - Download: https://git-scm.com/download

- **Docker** (optional, for some integrations)
  - Download: https://www.docker.com/products/docker-desktop

### Recommended

- **Visual Studio 2022** or **VS Code**
- **SQL Server Management Studio** (for database inspection)
- **Postman** or **REST Client** for API testing

## Cloning the Repository

```bash
git clone https://github.com/your-org/userorg.git
cd userorg
```

## Running Locally with Aspire

### Step 1: Install Aspire Tools

```bash
dotnet workload install aspire
```

### Step 2: Start the Application

```bash
cd src/UserOrg.AppHost
dotnet run
```

This will:
- Start SQL Server container
- Start all services (Gateway, Core API, etc.)
- Start Aspire Dashboard
- Initialize the database with migrations

### Step 3: Access Aspire Dashboard

Open your browser to:
```
http://localhost:17010
```

The dashboard shows:
- Running services and their status
- Resource usage (CPU, memory)
- Logs for each service
- Environment variables

## Basic Operations

### Health Check

```bash
curl http://localhost:5000/health
```

Should return:
```json
{
  "status": "Healthy",
  "checks": { ... }
}
```

### Get Projects

```bash
curl -H "Authorization: Bearer <token>" \
  http://localhost:5000/api/Project
```

### Create a Project

```bash
curl -X POST http://localhost:5000/api/Project \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{
    "shortName": "testproject",
    "name": "Test Project",
    "description": "My test project"
  }'
```

## Authentication

### Getting a Token (Development)

In development, tokens are typically generated by Keycloak:

1. Open Keycloak (usually http://localhost:8080)
2. Navigate to your realm
3. Get token via OAuth2 endpoint

For development testing, you might use:
```bash
curl -X POST http://localhost:8080/auth/realms/master/protocol/openid-connect/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=password&client_id=<client>&username=<user>&password=<pass>"
```

### Using API Key (Service-to-Service)

```bash
curl -H "X-API-Key: sk_xxxxxxxxxxxx" \
  http://localhost:5000/api/Project
```

## Database

### Viewing the Database

Using SQL Server Management Studio:
1. Connect to: `localhost`
2. Authentication: SQL Server Authentication
3. Login: `sa` / (password from AppHost)
4. Database: `UserOrgDBContext`

### Running Migrations

Migrations run automatically on startup. To manually run:

```bash
cd src/Core/Infrastructure.DataAccess
dotnet ef database update -c UserOrgDbContext
```

See [Database Guide](database.md) for more details.

⚠️ **Warning: This deletes all data**

```bash
cd src/Core/Infrastructure.DataAccess
dotnet ef database drop -c UserOrgDbContext
dotnet ef database update -c UserOrgDbContext
```

## Troubleshooting

### "Address already in use"
- Another process is using the port
- Stop other instances or change port in `appsettings.json`

### "Cannot connect to database"
- SQL Server isn't running
- Check Docker containers: `docker ps`
- Check Aspire Dashboard resource status

### "Aspire command not found"
- Install workload: `dotnet workload install aspire`
- Restart terminal

### "Migration failed"
- Check connection string
- Verify database exists
- Check migration files for syntax errors
